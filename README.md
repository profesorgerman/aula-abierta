# Aula abierta

Versión inicial de práctica de Matemáticas con las 35 preguntas del PDF 2023-N01 de la carpeta indicada. Abra index.html para usarla localmente. Puede publicar esta carpeta en GitHub Pages cuando esté conectada la cuenta correcta.

Incluye páginas originales, selección de respuestas, progreso local, reanudación, calificación, revisión y descarga CSV. La clave fue resuelta para esta práctica y no es una clave oficial del MEP. Conviene revisión docente antes de usarla para evaluación.

No está publicada. No hay sincronización automática con Drive ni almacenamiento central de resultados. No debe utilizarse para exámenes confidenciales: la clave es accesible en el navegador. Para evaluación formal se necesita un servicio de autenticación y calificación en el servidor.
